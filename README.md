# Labor & Baby Tracker

Single-page iPhone web app: contraction timer (start/stop, length, start-to-start interval, last-hour averages), labor notes, breastfeeding L/R timers, bottle (ml), diapers, timestamped notes. Data lives on the phone (localStorage); optional sync between phones via Supabase RPCs `lt_push` / `lt_pull` keyed by a random household code.

Host the repo root as a static site (GitHub Pages / Netlify), open in Safari, Share → Add to Home Screen.
